# ⛓ Blockchain Projects

A collection of decentralised applications (DApps) built on **Ethereum Sepolia Testnet** using Solidity, Ethers.js, and vanilla HTML/CSS/JS.

---

## 📁 Projects

| # | Project | Description | Folder |
|---|---------|-------------|--------|
| 1 | **CharityChain** | Transparent charity donation platform with campaigns, leaderboards, and donation certificates | [`charity-donation/`](./charity-donation/) |
| 2 | **AuctionChain** | Decentralised online auction platform with live bidding, countdown timers, and refund mechanism | [`auction/`](./auction/) |

---

## 🛠 Common Tech Stack

- **Solidity ^0.8.0** — Smart contracts
- **Remix IDE** — Compile & deploy
- **MetaMask** — Browser wallet
- **Ethereum Sepolia Testnet** — Test blockchain
- **Ethers.js v5.7** — Blockchain interaction
- **HTML5 / CSS3 / Vanilla JavaScript** — Frontend

---

## 🚀 Quick Start

1. Install [MetaMask](https://metamask.io) and switch to **Sepolia Testnet**
2. Get free test ETH from a [Sepolia faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia)
3. Navigate to any project folder and follow its `README.md` for setup instructions

---

*All projects use test ETH only — no real funds involved.*
